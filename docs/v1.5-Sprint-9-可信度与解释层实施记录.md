# 璀璨人生 v1.5 Sprint 9：可信度与解释层实施记录

## 目标

在年度事实聚合之后、年度报告 UI 之前，建立可验证的可信解释规则。只解释已有事实是否完整、来自哪里、为何不能比较，不生成建议、评分、预测或主观结论。

## 完成内容

### 覆盖状态

年度领域统一区分：

- `unconfigured`：年份规则未配置，例如尚无官方节假日数据；
- `no-records`：数据来源存在，但目标年份没有记录；
- `partial`：已有真实记录，但没有覆盖完整年度；
- `complete`：达到该领域完整年度的预期天数或月份数。

数据值为 `0` 时仍是事实。只有记录不存在或可选字段为 `null` 时才视为缺失。

### 来源和警告解释

- 保留机器稳定代码，另行返回中文解释；
- 支持健康每日汇总、官方节假日版本、个人日历修改、工资快照和职业经历来源；
- 支持健康缺日、可选健康指标缺失、日历年份未配置、工资月份不足和职业覆盖不足等警告；
- 未识别代码不被吞掉，明确返回“未识别”说明。

### 同比可比性门禁

允许指标限定为：

- 健康：年度总步数、平均步数、活动能量总量与均值、锻炼分钟总量；
- 财务：已保存工资快照的应发、个税和实发年度合计；
- 时间：官方工作日和最终工作日。

比较必须满足：

1. 两个不同年份；
2. 指标属于明确白名单；
3. 两个年度对应领域均为完整覆盖；
4. 两侧指标均为有限数值。

基准值为 `0` 时可以返回绝对差值，但百分比变化返回 `null`，避免除零和误导。

职业经历不做数值同比；人生事件、健康评分、工作评价和财务建议均不在本 Sprint 范围。
