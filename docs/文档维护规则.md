# 文档维护规则

- 持续更新：`项目状态.md`、`最终路线.md`、`数据字典.md`、`01-架构`、`02-领域`、`03-运维`。
- 冻结保存：`04-开发记录`、`05-里程碑`、`99-Archive`。历史事实只追加更正说明，不重写当时结论。
- 新的独立文档只用于长期有效的领域规则、可执行运维手册或完整里程碑；小型 UI、文案和修复只写入当月开发记录。
- 业务规则只在对应领域文档维护；实施记录可链接它，但不得成为第二份“当前规则”。
- 真实金额、数据量、Version ID 和备份哈希只放在里程碑或私有运维记录，不放进长期领域说明。
- 不在仓库或 Obsidian 中保存 API Key、PIN、Cookie、JWT、真实账单文件或数据库备份。
- Codex 阅读顺序：README → 项目状态 → 最终路线 → 架构与边界 → 目标领域 → 必要运维 → 最近开发记录。只有追溯决策时才读取里程碑与归档。
