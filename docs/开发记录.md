# 璀璨人生开发记录

## 项目目标

根据参考图片制作一个可部署到 Cloudflare 的健康训练仪表盘，包含训练结果、训练日历、每日步数、减重计划和习惯完成情况。

## 技术方案

- React 19 + TypeScript
- vinext / Vite
- Cloudflare Workers Static Assets
- Tailwind CSS 入口配合自定义 CSS
- 预留 Cloudflare D1 与 R2 绑定入口

## 已完成工作

### 2026-07-29：睡眠时长与趋势

- 健康数据模型新增可为空的每日睡眠分钟数，现有记录和体重数据不受影响。
- Health Auto Export 接口支持睡眠分析、整体睡眠以及 Core、Deep、REM 等睡眠阶段。
- 兼容汇总格式中的 `totalSleep`、`asleep`、Core、Deep 和 REM 字段，以及未汇总格式中的 `qty` 与起止时间。
- 自动排除 Awake 和 In Bed，避免把清醒或仅卧床时间误计为睡眠。
- 支持按起止时间计算，以及小时、分钟和秒单位换算。
- 健康趋势新增“睡眠”筛选，可查看 7 天或 30 天平均睡眠时长与每日记录。
- 不含睡眠的健康上传会保留同日已有睡眠数据。
- 修复汇总睡眠被写成 0 的问题，并将线上 6 条错误零值恢复为空值，等待重新同步真实数据。
- 完整构建与 6 项接口安全测试通过，D1 在迁移前完成备份并成功新增字段。

### 2026-07-25：Apple Watch / Apple 健康数据接入

- 启用 Cloudflare D1，新增按日期保存的健康数据表。
- 新增 `/api/health`：GET 读取最近一次汇总，POST 接收 iPhone 健康数据。
- 上传接口使用 `X-API-Key` 独立鉴权，并限制各项数值范围。
- 首期字段包括步数、活动能量、锻炼分钟数、训练次数与数据来源。
- 仪表盘会优先显示已同步的步数、活动能量和运动时长；未同步时显示示例值及提示。
- 手机端推荐使用 Health Auto Export，将 JSON 定时发送到 Worker 地址。
- 接口兼容 Health Auto Export Version 2 的 `data.metrics` 嵌套结构以及旧版顶层 `metrics` 数组，可识别 `step_count`、`active_energy` 和 Apple 锻炼时间，并按日期汇总写入。
