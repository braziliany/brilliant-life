# 璀璨人生开发记录

### 2026-08-13：Pulse 登录方案收敛为 One-time PIN

- Pulse Dashboard 仅保留 One-time PIN，关闭该应用中的 Cloudflare IdP 与 Instant Authentication；Cloudflare IdP 和 Apple 身份仍保留在账户层，没有删除账户或迁移域名。
- 删除仅为 Cloudflare Account Member + MFA 建立的 `Allow Cloudflare MFA`，最终仅保留 `Allow Owner → questioniar@outlook.com`；无 Bypass、Everyone 或宽泛 Email Domain Allow。
- Application Session 从 24 小时调整为 `2 weeks`（14 天），只影响 Pulse；保护范围仍为 `pulse.sophier.org/*`。
- 匿名访问首页、子路径和 Finance API 均返回 Access 302 登录跳转；Health ingest 的 workers.dev POST 无 Key与错 Key均返回 401。
- OTP 登录页已确认只显示邮箱与发送验证码入口，Cloudflare 已接受向授权邮箱发送 PIN 的请求；最终 PIN 登录与新 JWT 到期时间仍待邮箱送达后完成实机确认。
- 新增《Cloudflare Access 登录与恢复手册》，未修改业务代码、数据库、Worker、Health ingest 或 Finance，也未重新部署 Worker。

## 项目目标

根据参考图片制作一个可部署到 Cloudflare 的健康训练仪表盘，包含训练结果、训练日历、每日步数、减重计划和习惯完成情况。

## 技术方案

- React 19 + TypeScript
- vinext / Vite
- Cloudflare Workers Static Assets
- Tailwind CSS 入口配合自定义 CSS
- 预留 Cloudflare D1 与 R2 绑定入口
