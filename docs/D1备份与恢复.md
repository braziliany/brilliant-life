# Cloudflare D1 备份与恢复

璀璨人生的工作日历、工资、工作经历和健康数据保存在
`pulse-health-dashboard-db`。本项目采用两层保护：

1. Cloudflare D1 Time Travel：用于恢复最近 7 天（免费计划）或 30 天（付费计划）内的误操作。
2. 本地 SQL 导出：用于保留更久的独立副本。

## 创建本地备份

在项目根目录运行：

```powershell
npm run db:backup
```

备份会保存到本地 `backups` 文件夹，并输出 SHA256 校验值。该文件夹已被
Git 忽略，数据库内容不会上传到 GitHub。建议每月备份一次，并在修改数据库
结构或批量编辑数据之前额外备份。

至少保留：

- 最近 3 份月度备份；
- 每次数据库结构升级前的备份；
- 一份复制到另一块磁盘或加密云盘的异地副本。

## 从 SQL 文件恢复

恢复会写入远程数据库。先确认网站无人编辑，并核对文件日期。然后运行：

```powershell
npm run db:restore -- -BackupFile "backups\pulse-health-dashboard-db-年月日-时分秒.sql" -ConfirmRestore
```

恢复脚本会先自动导出恢复前的当前数据库，再执行导入。完成后检查：

- 工作日历与当月工作日数量；
- 工资参数及工资历史；
- 工作经历；
- 最近健康数据。

## 使用 Time Travel

查看当前恢复书签：

```powershell
npx wrangler d1 time-travel info pulse-health-dashboard-db
```

查看某个时间点对应的书签：

```powershell
npx wrangler d1 time-travel info pulse-health-dashboard-db --timestamp="2026-07-28T12:00:00+08:00"
```

Time Travel 会覆盖当前远程数据库，属于破坏性操作。恢复前必须先运行
`npm run db:backup`，并记录 Wrangler 返回的“恢复前书签”，以便撤销。

```powershell
npx wrangler d1 time-travel restore pulse-health-dashboard-db --bookmark="确认过的书签"
```

不要把未核对的备份导入生产数据库，也不要把 `backups` 文件夹提交到 GitHub。
