## 5. 计划提取的函数

拟新增 `app/features/calendar/domain.ts`。

### 5.1 calendarDateKey

将 0～11 月份输入格式化为 `YYYY-MM-DD`，保持补零行为不变。

### 5.2 getHolidayName

查询当前固定节假日范围，非节假日返回 `null`。

### 5.3 isMakeupWorkday

判断日期是否为当前固定调休上班日。

### 5.4 isOfficialWorkday

保持现有优先级：调休上班 → 法定节假日 → 普通星期。周一至周五工作，周末休息。

### 5.5 resolveCalendarDay

返回日期、假日、调休、官方状态、最终工作状态和个人覆盖状态。个人覆盖优先于官方日历，显式 `false` 必须有效。函数不生成 CSS 或 UI 文案。

### 5.6 getCalendarMonthShape

返回月初偏移、当月天数、含空位的日期数组和月历行数。继续使用星期一为第一列，空位使用 `null`。

### 5.7 countCalendarMonthWorkdays

按官方日历与个人覆盖统计指定月份工作日，结果继续作为工资模块的相同上游输入。

### 5.8 calculateAnnualWorkdays

返回 12 个月工作日数组与年度合计，使用年度覆盖集合且不读取 React 状态。

### 5.9 shiftCalendarMonth

纯计算月份偏移，正确处理 1 月、12 月和跨年边界。

### 5.10 getWorkdayToggle

返回日期键、是否已有覆盖、当前状态和下一状态。API 请求与乐观更新继续留在页面。

## 10. 风险点

| 风险 | 控制措施 |
|---|---|
| 节假日移动时遗漏 | 逐项特征测试锁定 |
| 调休优先级变化 | 固定判断顺序 |
| 显式 false 覆盖失效 | 使用 `??` 与键存在性测试 |
| 输入被修改 | 使用不可变计算并测试 |
| 月历星期偏移错误 | 锁定星期一首列算法 |
| 跨年切换错误 | 单独测试 1 月和 12 月 |
| 年度与月度覆盖混用 | 函数显式接收对应集合 |
| UI 文案或样式变化 | UI 映射留在 page.tsx |
| 工资结果变化 | 锁定工作日输入并回归工资 |
| 范围扩大 | 禁止扩展节假日年份和 API |
