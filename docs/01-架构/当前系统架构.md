# 当前系统架构

```text
Auto Export Health ─┐
官方工作日历 ───────┤
人工职业经历 ───────┤
Salary Records ─────┤→ 领域层 → API → Data Center / Annual Archive
钱迹导入 ───────────┘                    └→ Life Insights（只读派生）
```

## 运行边界

- Cloudflare Workers 承载页面与 API；D1 保存长期事实。
- `pulse.sophier.org/*` 由 Cloudflare Access 保护。
- Health 上传是独立机器接口，使用 `workers.dev` 和 API Key；业务页面/API 不信任该入口的伪造 Access 请求头。
- React 组件负责展示和交互，领域函数负责计算；UI 不重复实现工资、财务、日历、年度或洞察口径。
- Annual 是跨领域只读模型；Life Insights 再从已构建的年度事实派生，不写入 D1。

## 数据流

- Health：Auto Export Health → parser/normalizer → `health_daily` 与 ingest 状态 → Health domain。
- Calendar：年度官方配置 + D1 个人覆盖 → Calendar domain。
- Career：人工编辑 → `work_experiences` → Career domain。
- Salary：工作日历预计值或明确保存的 `salary_records` → Salary domain。
- Life Finance：钱迹 JSON/XLSX adapter → normalized transaction → `finance_transactions` → Finance domain。
- Annual：按年份与 `asOf` 读取各领域 → Annual domain → 年度页面。
- Insights：Annual/领域结果 → Insights domain → 年度页面说明卡。

详细边界见[数据与领域边界](./数据与领域边界.md)。
