# 数据与领域边界

| 领域 | 拥有的数据与规则 | 不负责 |
|---|---|---|
| Health | 健康指标、存在性、同步接收状态 | 医疗判断、后台执行保证 |
| Calendar | 官方日历、个人覆盖、工作日解析 | 工资金额 |
| Career | 经历排序、时长、年度重叠 | 工资和财务流水 |
| Salary | 工资政策、预计值、已保存快照 | 实际银行流水 |
| Life Finance | 导入交易、净消费、生活分类 | 重算工资、资产负债 |
| Annual Archive | `asOf` 下的跨领域只读汇总 | 修改源数据、自动补齐 |
| Life Insights | 有覆盖约束的派生说明 | 持久化结论、预测、评分 |

## 关键分界

- Salary 与 Life Finance 可以在 Annual 同时展示，但不相加、不自动匹配。
- Annual 是 read model，不是新的事实来源。
- Life Insights 是 derived model，不保存数据库，也不改变 Annual 数据。
- Finance 是实际流水视图，不是完整资产账本；transfer 与 repayment 的处理遵循 Finance domain。
- 每个来源保留 provenance；跨域展示不能抹掉来源和截止日期差异。
