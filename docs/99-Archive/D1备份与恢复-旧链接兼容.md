常用命令：

```powershell
npm run db:backup
npm run db:verify -- -Database "目标测试库" -MetadataFile "backups\日期\时间\metadata.json"
npm run db:restore -- -BackupFile "backups\日期\时间\database.sql" -Database "目标测试库" -ConfirmRestore
```

恢复脚本默认禁止写入生产数据库。不要把 `backups/`、SQL、metadata 或任何密钥提交到 GitHub。
