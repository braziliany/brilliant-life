## 生产基线

- 线上入口：`https://pulse.sophier.org`
- Worker：`pulse-health-dashboard`
- 数据库：Cloudflare D1，binding 为 `DB`
- 登录：Cloudflare Access One-time PIN，仅授权邮箱，应用会话 14 天
- Calendar Widget 机器入口：`GET /api/v1/calendar/widget` + 独立 Access Service Token，仅限该 path
- Health Ingest 机器入口：`POST /api/health/ingest` + 独立 Health Service Token + `X-API-Key`，仅限该 path
- Worker 公共入口：`workers_dev = false`、`preview_urls = false`
- Dashboard/private read：`pulse.sophier.org/*` + Owner Access；`/api/health` 不作为机器写入入口
- 本地环境：Node.js 22.x
- 发布门禁：`npm run verify` 与 `git diff --check`
- 页面入口：桌面使用唯一正式顶部导航；移动端隐藏全局导航控件、保留品牌及首页内部入口，直接 URL 和浏览器前进/后退仍可使用。

精确版本号、数据量和金额属于发布时点信息，保存在[里程碑](./05-里程碑/)而非本页。

## 不可破坏的语义

- Health 缺失不等于零；显式零值才是零。
- 已保存 Salary 快照不等于按当前日历计算的预计工资。
- Salary 收入事实不等于 Life Finance 中的实际收入流水，两者不自动对账。
- Life Finance 截止日期不等于 Annual `asOf`，两者必须分别表达。
- 当前年度 Annual 是截至 `asOf` 的 YTD 视图，未来日历配置须明确标记。
- Life Insights 是由已存在事实临时计算的派生结果，不持久化、不反写源数据。
- Life Timeline 同样只组织现有稳定事实，不创建新的事件事实层或时间线快照。
- Timeline 不因 Calendar Notes 或 Finance 候选记录扩展成另一份 Annual Archive，也不提供 CRUD、AI summary 或 importance score。
