# 璀璨人生 v1.4 Sprint 2：健康领域逻辑收敛实施计划

## 1. Sprint 目标

将 `page.tsx` 中现有的健康数据派生计算提取为纯 health domain functions，降低健康模块的维护风险，同时保证页面行为完全一致。

核心原则：

> 只移动纯计算，不移动状态、副作用、接口调用或展示逻辑。

## 2. 冻结边界

### 允许修改

- `app/page.tsx`
- 新增 `app/features/health/domain.ts`
- 新增 `tests/health-domain.test.mjs`
- 必要时移动健康领域类型，但不改变字段定义

### 禁止修改

- `app/features/health/HealthOverviewCard.tsx`
- `app/features/health/DailyGoalsColumn.tsx`
- `app/globals.css`
- `app/api/**`
- `db/**`
- `drizzle/**`
- `public/**`
- `package.json`
- `package-lock.json`
- `.openai/hosting.json`
- Health Auto Export 字段、名称、单位和 JSON 结构

### 必须留在 `page.tsx` 的内容

- `useState`、`useEffect`
- `fetch("/api/health?days=30")`
- 请求成功与失败处理
- 页面可见性与焦点刷新监听
- `localStorage` 步数目标读取和保存
- CSV 下载的 Blob、URL 和 DOM 操作
- 所有 UI 状态切换
- 组件 JSX 和现有 props 契约

## 3. 计划提取的领域函数

拟新增：

```text
app/features/health/domain.ts
```

### 3.1 当日健康数据选择

```ts
selectTodayHealth(history, todayKey)
```

职责：

- 按上海日期键选择当天记录；
- 没有当天数据时返回 `null`；
- 不修改传入数组。

保持当前行为：

```ts
history.find((item) => item.date === todayKey) ?? null
```

### 3.2 历史数据排序转换

```ts
toChronologicalHealthHistory(history)
```

职责：

- 将接口返回历史转换为当前页面所使用的时间顺序；
- 使用复制后反转，不能修改接口返回的原数组。

保持当前行为：

```ts
[...history].reverse()
```

### 3.3 今日健康摘要

```ts
calculateHealthSummary(health, stepGoal)
```

返回：

- `steps`
- `stepProgress`
- `activeEnergy`
- `totalEnergy`
- `exerciseHours`

必须完整保留当前规则：

- 没有健康数据时步数为 `0`；
- 目标进度最多为 `100%`；
- 活动能量使用 `Math.round`；
- 只有静息能量大于 `0` 时才计算总能量；
- 锻炼分钟换算为小时并保留一位小数。

### 3.4 健康指标取值

```ts
getHealthMetricValue(record, metric)
```

规则保持不变：

- 体重缺失时按 `0` 参与既有图表计算；
- 睡眠分钟转换为小时；
- 静息心率缺失时返回 `0`；
- 步数、能量和锻炼时间直接读取。

### 3.5 健康趋势统计

```ts
calculateHealthTrend(history, period, metric)
```

返回：

- `visibleHistory`
- `metricHistory`
- `metricMax`
- `metricAverage`
- `metricAverageLabel`

保持当前规则：

- 只读取最近 7 天或 30 天；
- 体重、睡眠和静息心率过滤 `null`；
- 图表最大值至少为 `1`；
- 无数据时平均值为 `0`；
- 体重和睡眠平均值保留一位小数；
- 其他指标四舍五入并使用中文数字格式。

颜色、单位、中文标题继续留在页面或现有组件中，因为它们属于展示配置，不属于领域算法。

### 3.6 体重趋势统计

```ts
calculateWeightTrend(history)
```

返回：

- `recentWeightHistory`
- `latestWeight`
- `weightChange`
- `recentWeightMin`
- `recentWeightRange`

保持当前规则：

- 过滤没有体重的数据；
- 只使用最近 14 条体重记录；
- 至少两条记录才计算变化；
- 图表范围最小为 `0.1`；
- 没有数据时保持当前默认值和空状态。

### 3.7 今日缺失指标

```ts
getMissingTodayHealthMetrics(health)
```

返回领域键值：

```ts
("weightKg" | "sleepMinutes" | "restingHeartRateBpm")[]
```

`page.tsx` 继续负责映射为现有中文文案：

- `weightKg` → 体重
- `sleepMinutes` → 睡眠
- `restingHeartRateBpm` → 静息心率

这样领域函数不嵌入 UI 文案，同时页面最终显示完全不变。
