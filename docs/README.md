- `03-运维`：部署、访问控制、备份、同步与本地预览。
- `04-开发记录`：按月追加的变更记录。
- `05-里程碑`：完成版本的计划、实施和验收原文，只读保存。
- `99-Archive`：已被当前文档替代但仍需追溯的旧文档。
