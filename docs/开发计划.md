# 璀璨人生开发计划

> [!summary] 项目定位
> 将 Pulse 从健康仪表盘逐步完善为整合健康、工作、工资与个人生活数据的“璀璨人生”数字仪表盘。

## 项目入口

- 线上地址：[pulse.sophier.org](https://pulse.sophier.org)
- GitHub：[braziliany/brilliant-life](https://github.com/braziliany/brilliant-life)
- 部署平台：Cloudflare Workers
- 数据存储：Cloudflare D1
- 关联记录：[[开发记录]]

## 当前版本

### Pulse 1.1（已完成）

- [x] 响应式健康仪表盘
- [x] Apple 健康数据导入
- [x] 工资实时计算
- [x] 工作日历及月份切换
- [x] 2026 年法定节假日与调休
- [x] 工作日历手动编辑
- [x] 编辑结果保存至 Cloudflare D1
- [x] 手机端日历编辑入口
- [x] Cloudflare Access 登录保护
- [x] 自定义 Pulse 品牌图标

## 下一阶段计划

### P0：稳定性与数据安全

- [ ] 为健康数据上传接口轮换 API Key，避免长期使用同一密钥
- [ ] 增加 API 请求失败时的友好提示与重试机制
- [ ] 检查 Cloudflare D1 数据迁移和备份方案
- [ ] 为日历编辑和工资计算补充自动化测试
- [ ] 验证桌面端、iPhone Safari 和不同屏幕尺寸的核心流程

### P1：工资 1.2

- [x] 保存每月工资记录
- [x] 增加工资历史列表
- [x] 增加应发、扣除、个税、实发的月度趋势图
- [x] 支持调整日薪、固定扣除、起征点和税率
- [x] 支持额外收入、请假扣款和奖金
- [x] 支持工资记录导出

### P1：工作日历 1.2

- [x] 增加编辑状态说明和撤销修改功能
- [x] 增加“恢复官方日历”操作
- [x] 显示节假日名称
- [ ] 区分法定节假日、调休上班、周末和个人修改
- [ ] 支持查看全年工作日统计
- [ ] 支持按月备注排班、请假和加班

### P1：健康数据 1.2

- [ ] 展示每日步数、活动能量和锻炼时长趋势
- [ ] 增加最近 7 天和最近 30 天视图
- [ ] 增加同步时间及数据来源状态
- [ ] 支持体重、睡眠、静息心率等更多健康指标
- [ ] 优化 Health Auto Export 自动同步说明

### P2：体验与品牌

- [ ] 统一桌面端与移动端交互反馈
- [ ] 增加暗色/亮色主题切换
- [ ] 完善侧边导航的页面切换和选中状态
- [ ] 增加加载、空数据和错误状态
- [ ] 继续完善“璀璨人生”品牌文案与视觉系统
- [ ] 增加 PWA 安装支持

## 建议版本路线

| 版本 | 目标 | 状态 |
| --- | --- | --- |
| 1.1 | 健康同步、可编辑工作日历、实时工资 | 已完成 |
| 1.2 | 工资历史、健康趋势、日历体验完善 | 计划中 |
| 1.3 | 更多健康指标、年度统计、数据导出 | 待规划 |
| 2.0 | 健康、工作、财务和生活记录统一仪表盘 | 愿景 |

## 每次开发完成清单

- [ ] 更新功能代码
- [ ] 执行 `npm run build`
- [ ] 执行相关测试
- [ ] 更新 [[开发记录]]
- [ ] 提交并推送到 GitHub
- [ ] 部署到 Cloudflare
- [ ] 验证线上核心功能
- [ ] 更新本计划中的任务状态

## 备注

- 工作日数量以工作日历的最终状态为准，工资模块应实时读取该结果。
- 法定节假日和调休信息需要按年份维护，并以国务院正式通知为准。
- Cloudflare Access 负责网站访问保护，健康数据上传接口继续使用独立密钥鉴权。
