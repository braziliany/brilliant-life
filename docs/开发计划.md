## 约束与原则

- 页面中不展示虚构健康、工资或工作数据。
- 工作日数量以可编辑工作日历的最终状态为准。
- 法定节假日和调休以正式通知为准，按年份维护。
- 持久数据优先保存到 Cloudflare D1，不以浏览器缓存作为唯一数据源。
- Cloudflare Access 负责网页访问保护，健康上传接口使用独立密钥。
