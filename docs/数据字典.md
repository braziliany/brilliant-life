# 数据字典

本文件定义跨领域通用语义。具体字段与规则以对应领域文档和 `db/schema.ts` 为准。

## 存在性与可信度

| 术语 | 含义 |
|---|---|
| missing | 来源没有提供有效值；不得显示或统计为 0 |
| explicit zero | 来源明确提供且解析为 0；是有效事实，可进入分母 |
| legacy unknown | 早期记录缺少指标级存在性信息；保留旧统计兼容，但不计入可信覆盖 |
| trusted coverage | 新协议明确确认指标 present 的记录范围 |
| confirmed missing | 新协议处理过但 coverage 不包含该指标 |

Health 的 `metric_coverage`：`NULL` 为 legacy unknown，`[]` 为该日无有效指标，JSON 数组中的 key 表示对应指标 present。

## 事实类型

| 术语 | 含义 |
|---|---|
| actual | 已经发生并由来源记录的事实，如健康日记录或流水 |
| saved snapshot | 用户明确保存的时点快照，如月度工资历史；不按新规则重算 |
| estimated | 根据当前配置即时计算、尚未固化的值，如本月预计工资 |
| derived | 从已有事实纯计算得到的摘要或洞察；不是新的源事实 |

## 时间与覆盖

| 术语 | 含义 |
|---|---|
| `asOf` | Annual 当前允许陈述事实的截止日期；当前年度形成 YTD |
| `cutoff` / `dateEnd` | 某个来源实际拥有记录的最后日期，可能早于 `asOf` |
| coverage | 实际可用于某项统计的日期、月份或记录范围 |
| configured year | Calendar 有官方节假日文件的年份；不代表未来日期已经发生 |

## 财务交易类型

| 类型 | 含义 | 是否进入净消费 |
|---|---|---|
| income | 实际收入流水 | 否，单独累计收入 |
| expense | 支出 | 正向计入 |
| refund | 退款 | 从支出中扣减 |
| transfer | 账户间转移 | 否 |
| repayment | 还款类资金移动 | 否 |

- 净消费（net expense）=`expense - refund`。
- 现金流余额（cash-flow balance）是收入与纳入现金流的支出之间的派生差额，不等于资产净值，也不用于自动对账 Salary。

## 核心持久表

| 表 | 领域 | 关键身份/约束 |
|---|---|---|
| `health_daily` | Health | 每个上海自然日一行；含 nullable `metric_coverage` |
| `health_ingestion_runs` | Health 运维 | 服务端真实接收事件与日期范围 |
| `calendar_overrides` | Calendar | 日期唯一的个人状态覆盖 |
| `calendar_notes` | Calendar | 月份唯一的自然文本备注 |
| `salary_records` | Salary | 月份唯一的已保存快照 |
| `salary_settings` | Salary | 旧兼容设置；当前政策以代码为准 |
| `work_experiences` | Career | 月份精度经历记录 |
| `finance_transactions` | Life Finance | `(source, source_id)` 唯一，金额以整数分保存 |

Annual Archive 与 Life Insights 不拥有持久表：前者是跨域 read model，后者是只读 derived model。
