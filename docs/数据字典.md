# 璀璨人生数据字典

本文以 2026-08-08 的生产 `sqlite_schema` 与 `db/schema.ts` 交叉核对。SQLite `INTEGER PRIMARY KEY` 同时是 rowid；日期和月份使用固定文本格式。

## `health_daily`

按上海日期保存 Health Auto Export 的每日汇总，`date` 唯一。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `date` | text | 否 | `YYYY-MM-DD` 上海日期 |
| `steps` | integer | 否 | 步数，默认 0 |
| `active_energy_kcal` | real | 否 | 活动能量，千卡 |
| `resting_energy_kcal` | real | 否 | 静息能量，千卡 |
| `exercise_minutes` | real | 否 | Apple 锻炼分钟数 |
| `workout_count` | integer | 否 | 训练记录数量 |
| `weight_kg` | real | 是 | 体重；`null` 表示未上传，不能解释为 0 |
| `sleep_minutes` | real | 是 | 睡眠分钟数；`null` 表示未上传 |
| `resting_heart_rate_bpm` | real | 是 | 静息心率；`null` 表示未上传 |
| `source` | text | 否 | 数据来源标识，例如健康导出客户端 |
| `updated_at` | text | 否 | 最近写入时间 |

唯一索引：`health_daily_date_unique(date)`。

### 健康字段可信语义

| 状态 | 含义 | 页面展示 | 趋势使用 |
|---|---|---|---|
| 本次上传包含指标且值大于 0 | 有真实汇总值 | 可以显示 | 可以使用 |
| 本次上传明确包含指标且值为 0 | 真实零值，不等于缺字段 | 可以按指标含义显示 | 可以使用 |
| 本次上传未包含指标 | 本次请求没有提供该指标 | 不应显示为新测量值 | 不新增趋势点 |
| `weight_kg`、`sleep_minutes` 或 `resting_heart_rate_bpm` 为 `null` | 尚无有效测量 | 显示暂无数据 | 不使用 |
| 当天没有 `health_daily` | 没有该数据日期记录 | 显示当天无数据 | 不使用 |

`health_daily` 表示每日最终汇总，不表示上传事件。Sprint 7 Step 1 起，同日部分上传只更新请求实际包含且有效的字段；归一化产生的默认 `0` 不再覆盖本次未包含的已有指标。历史记录不做推测性修正。

## `health_ingestion_runs`

记录低敏感度的健康上传事件，用于解释最近上传时间、连续性、解析结果和指标覆盖。该表不保存原始请求内容。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `received_at` | text | 否 | Worker 收到已认证请求的 UTC 时间 |
| `covered_dates` | text | 否 | 本次成功解析的数据日期 JSON 数组 |
| `metric_keys` | text | 否 | 本次有效支持指标键 JSON 数组 |
| `imported_days` | integer | 否 | 本次写入或更新的每日汇总数量 |
| `status` | text | 否 | `success`、`no_supported_metrics` 或 `invalid_payload` |
| `source` | text | 是 | 限长后的来源类别，不记录设备名称 |

索引：`health_ingestion_runs_received_at_idx(received_at)`，用于按最近接收时间读取。禁止在此表保存原始 Health Auto Export JSON、API Key、Access Token、完整请求头、设备名称或 HealthKit 明细。

## `calendar_overrides`

只保存用户对官方工作日历的显式覆盖；没有记录表示采用官方规则。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `date` | text | 否 | `YYYY-MM-DD` |
| `is_workday` | integer | 否 | SQLite 布尔值，1 为工作、0 为休息 |
| `updated_at` | text | 否 | 最近修改时间 |

唯一索引：`calendar_overrides_date_unique(date)`。法定节假日和调休规则在代码中维护，不存入此表。

### 官方节假日年度文件

官方节假日按年度冻结在 `app/features/calendar/holiday-data/<year>.ts`，当前已配置 2026 年。

- `getHolidayCalendar(year)` 返回 `configured` 或 `unconfigured`；
- 未配置年份只允许使用普通星期规则和个人修改进行临时浏览；
- 未配置年份不得保存或同步工资记录；
- 新年度数据必须依据正式通知新增独立文件，并通过全年工作日、节假日边界和工资回归测试，不得覆盖旧年度文件。

## `calendar_notes`

保存每月自由文本备注，不参与工资自动计算，`month` 唯一。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `month` | text | 否 | `YYYY-MM` |
| `schedule_note` | text | 否 | 排班备注 |
| `leave_note` | text | 否 | 请假备注 |
| `overtime_note` | text | 否 | 加班备注 |
| `updated_at` | text | 否 | 最近修改时间 |

唯一索引：`calendar_notes_month_unique(month)`。

## `salary_records`

保存已确认月份的完整工资快照。历史记录不能根据新政策或新日历重新计算，`month` 唯一。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `month` | text | 否 | `YYYY-MM` |
| `workdays` | integer | 否 | 保存时的工作日数 |
| `daily_rate` | real | 否 | 保存时日薪 |
| `deductions` | real | 否 | 固定扣除 |
| `tax_threshold` | real | 否 | 个税起征点 |
| `tax_rate` | real | 否 | 税率百分数 |
| `extra_income` | real | 否 | 额外收入 |
| `bonus` | real | 否 | 奖金 |
| `leave_deduction` | real | 否 | 请假扣款 |
| `gross_salary` | real | 否 | 应发工资快照 |
| `taxable_income` | real | 否 | 计税收入快照 |
| `income_tax` | real | 否 | 个税快照 |
| `net_salary` | real | 否 | 实发工资快照 |
| `updated_at` | text | 否 | 保存时间 |

唯一索引：`salary_records_month_unique(month)`。

## `salary_settings`

保存后端固定工资政策的持久化记录。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | text | 否 | 设置记录主键 |
| `daily_rate` | real | 否 | 日薪，默认 275 |
| `deductions` | real | 否 | 固定扣除，默认 130 |
| `tax_threshold` | real | 否 | 起征点，默认 5000 |
| `tax_rate` | real | 否 | 税率，默认 3 |
| `updated_at` | text | 否 | 最近更新时间 |

额外收入、奖金和请假扣款属于当前计算输入，不存入此设置表；保存后进入 `salary_records` 快照。

## `work_experiences`

保存职业经历，页面按 `start_date`、`id` 升序展示。

| 字段 | 类型 | 可空 | 语义 |
|---|---|---|---|
| `id` | integer | 否 | 自增主键 |
| `company` | text | 否 | 单位名称 |
| `role` | text | 否 | 职位 |
| `start_date` | text | 否 | 开始年月 `YYYY-MM` |
| `end_date` | text | 是 | 结束年月；`null` 表示至今 |
| `summary` | text | 否 | 工作内容，默认空字符串 |
| `sort_order` | integer | 否 | 历史兼容字段；当前展示不依赖手动排序 |
| `updated_at` | text | 否 | 最近修改时间 |

## Cloudflare 内部表

`_cf_KV` 由 Cloudflare D1 管理。完整 SQL 导出会处理平台所需内容，但业务代码、数据字典和行数验收不把它当作业务表。
